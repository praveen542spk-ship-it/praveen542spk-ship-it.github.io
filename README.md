## 🚀 Key Highlights & Design Direction

- **Futuristic Minimalist Dark Aesthetic**: Ambient glowing background gradient orbs, animated grid mesh, and frosted liquid glassmorphism cards.
- **Responsive 2026 UI Grid Layouts**: Mobile-first architecture supporting everything from 320px screens to 4K desktop displays.
- **Top Scroll Progress Indicator**: Visual indicator tracking page scroll position.
- **Interactive Light/Dark Mode**: Persisted theme switching with anti-flicker pre-render script.
- **Full Web Accessibility (WCAG 2.1 Compliant)**: Includes skip-to-content navigation, semantic HTML5 tags, full keyboard focus rings (`:focus-visible`), and ARIA attributes.
- **Interactive Code Editor Widget**: Clean developer JSON object snippet in the About section with one-click copy to clipboard.
- **Featured Project Showcase + Filterable Projects Grid**: Highlight banner for top projects + interactive technology filters (`All`, `React`, `Node.js`, `Python`, `JavaScript`).
- **Interactive Photo Lightbox**: Clickable profile photos opening in full-screen glass modal with keyboard (ESC) and click-outside dismissal.
- **Functional Contact Form (Web3Forms Integration)**: Direct AJAX submissions to `praveen542spk@gmail.com` with real-time field validation and success states.
